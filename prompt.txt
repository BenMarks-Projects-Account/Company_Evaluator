# Company Evaluator: Phase 2 Universe Expansion

## Scope: Company Evaluator project ONLY
## Service URL: http://192.168.1.143:8100

## Background

The data quality bulletproofing is complete. The breakout score
is working. NAS storage is in place. Now we expand the universe
from ~800 to ~2,500 symbols with a focus on finding small/mid
cap companies that have the potential to become tomorrow's large
caps.

## Goal

Build a universe expansion pipeline that:
1. **Discovers** quality candidates using multi-criteria screening
2. **Filters** out junk before evaluation cycles are wasted
3. **Tags** companies with tier metadata for future use
4. **Inserts** them into the existing universe table

**This prompt does NOT modify the crawler.** The crawler will pick
up new symbols using its existing staleness-based ordering. We'll
add tier-priority logic to the crawler in a follow-up prompt only
if needed after observing how the expansion plays out.

The `tier` and `refresh_days` columns are added to the schema and
populated for new symbols, but no code reads them yet. They're
metadata for future use.

## Strategic principles

1. **Quality over quantity.** A 2,500-symbol universe of pre-screened
   companies is better than a 5,000-symbol universe of everything.

2. **The breakout score filters most stuff.** The hard filters
   ($500M-$50B, $100M+ revenue, no funds/warrants) will reject ~50%
   of any random sample. Pre-screening at ingestion saves crawler
   cycles.

3. **Tiered refresh rates.** Higher conviction = fresher data.
   Lower conviction = less frequent updates. This is how we fit
   2,500 symbols into the 7-day window.

4. **Diverse discovery sources.** Multi-criteria screening + IPO
   calendar + smart money signals = broader coverage than any
   single source.

5. **Idempotent ingestion.** Running the universe builder multiple
   times should add new symbols without duplicating or breaking
   existing entries.

## Final decisions baked into this version

These decisions were made before writing the prompt — do not
relitigate them during implementation:

- **Tier 2 floor: $500M.** More discovery surface area, accepting
  more noise that the breakout score will filter.

- **Tier 3 limited to ~200 highest-volume names.** Speculative
  microcaps are kept lean for discovery value only. Volume floor
  raised to 1M shares/day, price floor to $7.

- **Sector screens kept.** They extend the cap range up to $20B
  for Technology / Healthcare / Communication Services / Consumer
  Cyclical, biasing the universe toward growth sectors.

- **Target: ~2,500 symbols total** (current ~800 + ~1,700 new).

```python
async def stock_screener(
    self,
    market_cap_min: float | None = None,
    market_cap_max: float | None = None,
    price_min: float | None = None,
    volume_min: float | None = None,
    beta_min: float | None = None,
    beta_max: float | None = None,
    sector: str | None = None,
    industry: str | None = None,
    country: str = "US",
    exchange: str = "nyse,nasdaq",
    is_actively_trading: bool = True,
    is_etf: bool = False,
    is_fund: bool = False,
    limit: int = 1000,
) -> list[dict] | None:
    """
    FMP stock screener.
    
    Returns list of companies matching the criteria, with basic
    fields like symbol, name, market cap, sector, industry, price.
    """
    params = {"apikey": self.api_key}
    
    if market_cap_min is not None:
        params["marketCapMoreThan"] = market_cap_min
    if market_cap_max is not None:
        params["marketCapLowerThan"] = market_cap_max
    if price_min is not None:
        params["priceMoreThan"] = price_min
    if volume_min is not None:
        params["volumeMoreThan"] = volume_min
    if beta_min is not None:
        params["betaMoreThan"] = beta_min
    if beta_max is not None:
        params["betaLowerThan"] = beta_max
    if sector:
        params["sector"] = sector
    if industry:
        params["industry"] = industry
    if country:
        params["country"] = country
    if exchange:
        params["exchange"] = exchange
    if is_actively_trading:
        params["isActivelyTrading"] = "true"
    if not is_etf:
        params["isEtf"] = "false"
    if not is_fund:
        params["isFund"] = "false"
    
    params["limit"] = limit
    
    return await self._fetch(
        "/company-screener",  # or whatever the actual stable path is
        params=params,
        return_list=True
    )
```

## Step 4: Build the universe expansion service

Create `app/services/universe_expansion.py`:

```python
"""
Phase 2 universe expansion service.

Discovers and onboards quality candidates for the company evaluator
using multi-criteria screening, IPO calendar, and smart money signals.
"""

import logging
import json
from datetime import datetime, timedelta
from typing import Any

from app.services.data.fmp_client import fmp_client
from app.services.data.finnhub_client import finnhub_client
from app.db import get_db_connection

logger = logging.getLogger(__name__)


# Exclusion filters applied to all discovered symbols
EXCLUSION_FILTERS = {
    "name_contains": [
        "acquisition corp",
        "holdings",  # most holdcos are noise — careful, may be too aggressive
        "blank check",
        "spac",
        "trust",
        "preferred",
        "warrant",
    ],
    "symbol_suffixes": ["W", "U", "R", ".W", ".U", ".R", "-W", "-U"],
    "excluded_sectors": [
        # Investment funds and REITs need separate evaluation models
        # Decide whether to exclude or include with different tier
    ],
}


async def expand_universe(dry_run: bool = True) -> dict:
    """
    Run the full universe expansion pipeline.
    
    Args:
        dry_run: If True, report what would be added without inserting
    
    Returns:
        {
            "discovered": int,
            "filtered_out": int,
            "added": int,
            "skipped_existing": int,
            "tier_breakdown": {...},
            "source_breakdown": {...},
        }
    """
    logger.info(f"Starting universe expansion (dry_run={dry_run})")
    
    # Get current universe to avoid duplicates
    existing = get_existing_symbols()
    logger.info(f"Existing universe: {len(existing)} symbols")
    
    # Discover candidates from multiple sources in parallel
    discovered = []
    
    # Source 1: FMP screener — Tier 2 Breakout Zone (the big one)
    breakout_zone = await discover_breakout_zone()
    discovered.extend(breakout_zone)
    logger.info(f"Discovered {len(breakout_zone)} breakout zone candidates")
    
    # Source 2: FMP screener — Tier 3 Small Cap
    small_caps = await discover_small_caps()
    discovered.extend(small_caps)
    logger.info(f"Discovered {len(small_caps)} small cap candidates")
    
    # Source 3: FMP screener — Sector-focused (high-growth tech, biotech, etc.)
    sector_focused = await discover_sector_focused()
    discovered.extend(sector_focused)
    logger.info(f"Discovered {len(sector_focused)} sector-focused candidates")
    
    # Source 4: Finnhub IPO calendar — recent IPOs
    recent_ipos = await discover_recent_ipos()
    discovered.extend(recent_ipos)
    logger.info(f"Discovered {len(recent_ipos)} recent IPO candidates")
    
    # Deduplicate (same symbol may come from multiple sources)
    seen = set()
    unique_candidates = []
    for c in discovered:
        symbol = c.get("symbol")
        if symbol and symbol not in seen:
            seen.add(symbol)
            unique_candidates.append(c)
    
    logger.info(f"Total unique candidates: {len(unique_candidates)}")
    
    # Apply exclusion filters
    filtered = [c for c in unique_candidates if not should_exclude(c)]
    excluded_count = len(unique_candidates) - len(filtered)
    logger.info(f"After exclusion filters: {len(filtered)} (excluded {excluded_count})")
    
    # Skip companies already in universe
    new_candidates = [c for c in filtered if c.get("symbol") not in existing]
    skipped_existing = len(filtered) - len(new_candidates)
    logger.info(f"New candidates (not already in universe): {len(new_candidates)}")
    
    # Assign tier and metadata
    for c in new_candidates:
        c["tier"] = assign_tier(c)
        c["refresh_days"] = TIER_DEFINITIONS[c["tier"]]["refresh_days"]
    
    # Build summary
    tier_breakdown = {}
    source_breakdown = {}
    for c in new_candidates:
        tier = c.get("tier", "unknown")
        source = c.get("discovery_source", "unknown")
        tier_breakdown[tier] = tier_breakdown.get(tier, 0) + 1
        source_breakdown[source] = source_breakdown.get(source, 0) + 1
    
    # Insert into universe (or just report if dry_run)
    added = 0
    if not dry_run:
        added = insert_into_universe(new_candidates)
    
    return {
        "discovered": len(unique_candidates),
        "filtered_out": excluded_count,
        "skipped_existing": skipped_existing,
        "added": added if not dry_run else len(new_candidates),
        "dry_run": dry_run,
        "tier_breakdown": tier_breakdown,
        "source_breakdown": source_breakdown,
    }


# === DISCOVERY FUNCTIONS ===

async def discover_breakout_zone() -> list[dict]:
    """
    Discover Tier 2 candidates: $500M-$10B market cap, profitable
    or near-profitable, decent volume.
    
    This is the bulk of the expansion — the "next mega cap" hunting ground.
    """
    candidates = []
    
    # Run the screener in chunks to stay within result limits
    # Chunk 1: $500M - $2B
    chunk1 = await fmp_client.stock_screener(
        market_cap_min=500_000_000,
        market_cap_max=2_000_000_000,
        price_min=5.0,
        volume_min=200_000,
        country="US",
        exchange="nyse,nasdaq",
        is_actively_trading=True,
        limit=1000,
    )
    
    if chunk1:
        for company in chunk1:
            candidates.append({
                "symbol": company.get("symbol"),
                "name": company.get("companyName"),
                "market_cap": company.get("marketCap"),
                "sector": company.get("sector"),
                "industry": company.get("industry"),
                "price": company.get("price"),
                "discovery_source": "fmp_screener_breakout_zone_1",
            })
    
    # Chunk 2: $2B - $10B
    chunk2 = await fmp_client.stock_screener(
        market_cap_min=2_000_000_000,
        market_cap_max=10_000_000_000,
        price_min=5.0,
        volume_min=200_000,
        country="US",
        exchange="nyse,nasdaq",
        is_actively_trading=True,
        limit=1000,
    )
    
    if chunk2:
        for company in chunk2:
            candidates.append({
                "symbol": company.get("symbol"),
                "name": company.get("companyName"),
                "market_cap": company.get("marketCap"),
                "sector": company.get("sector"),
                "industry": company.get("industry"),
                "price": company.get("price"),
                "discovery_source": "fmp_screener_breakout_zone_2",
            })
    
    return candidates


async def discover_small_caps() -> list[dict]:
    """
    Discover Tier 3 candidates: $300M-$500M market cap.
    
    TRIMMED VERSION: Only the ~200 highest-volume names. These are
    speculative microcaps that may cross the $500M breakout threshold
    eventually. We crawl them at 14-day intervals for discovery value
    only — most will never qualify for breakout scoring.
    
    Quality bars are HIGHER than other tiers because we're being
    selective:
    - Volume floor: 1M shares/day (vs 200K elsewhere)
    - Price floor: $7 (vs $5 elsewhere)
    """
    result = await fmp_client.stock_screener(
        market_cap_min=300_000_000,
        market_cap_max=500_000_000,
        price_min=7.0,            # Higher than other tiers
        volume_min=1_000_000,     # 1M+ shares/day for real liquidity
        country="US",
        exchange="nyse,nasdaq",
        is_actively_trading=True,
        limit=300,                # Fetch 300 to allow for filtering
    )
    
    if not result:
        return []
    
    # Sort by volume descending and take top 200
    result.sort(
        key=lambda c: c.get("volume") or 0,
        reverse=True
    )
    top_200 = result[:200]
    
    candidates = []
    for company in top_200:
        candidates.append({
            "symbol": company.get("symbol"),
            "name": company.get("companyName"),
            "market_cap": company.get("marketCap"),
            "sector": company.get("sector"),
            "industry": company.get("industry"),
            "price": company.get("price"),
            "discovery_source": "fmp_screener_small_cap_top200",
        })
    
    return candidates


async def discover_sector_focused() -> list[dict]:
    """
    Discover sector-focused candidates in high-growth sectors,
    regardless of market cap (within reasonable bounds).
    
    Focus sectors:
    - Technology (AI, software, semis)
    - Healthcare (biotech with revenue)
    - Communication Services
    - Consumer Discretionary (DTC, e-commerce)
    """
    candidates = []
    
    target_sectors = [
        "Technology",
        "Healthcare",
        "Communication Services",
        "Consumer Cyclical",  # FMP's name for consumer discretionary
    ]
    
    for sector in target_sectors:
        result = await fmp_client.stock_screener(
            sector=sector,
            market_cap_min=500_000_000,
            market_cap_max=20_000_000_000,
            price_min=5.0,
            volume_min=200_000,
            country="US",
            exchange="nyse,nasdaq",
            is_actively_trading=True,
            limit=500,
        )
        
        if result:
            for company in result:
                candidates.append({
                    "symbol": company.get("symbol"),
                    "name": company.get("companyName"),
                    "market_cap": company.get("marketCap"),
                    "sector": company.get("sector"),
                    "industry": company.get("industry"),
                    "price": company.get("price"),
                    "discovery_source": f"fmp_screener_sector_{sector.lower().replace(' ', '_')}",
                })
    
    return candidates


async def discover_recent_ipos() -> list[dict]:
    """
    Discover companies that IPO'd in the last 2 years.
    
    These are interesting because they're often missed by traditional
    screeners and may not have stable fundamentals yet but have
    high growth potential.
    """
    candidates = []
    
    try:
        # Finnhub IPO calendar
        from_date = (datetime.utcnow() - timedelta(days=730)).strftime("%Y-%m-%d")
        to_date = datetime.utcnow().strftime("%Y-%m-%d")
        
        ipos = await finnhub_client.get_ipo_calendar(
            from_date=from_date,
            to_date=to_date
        )
        
        if ipos and isinstance(ipos, dict):
            ipo_list = ipos.get("ipoCalendar", [])
        else:
            ipo_list = ipos or []
        
        for ipo in ipo_list:
            symbol = ipo.get("symbol")
            exchange = ipo.get("exchange", "")
            price = ipo.get("price")
            
            # Filter to NYSE/NASDAQ only
            if not symbol or "NASDAQ" not in exchange.upper() and "NYSE" not in exchange.upper():
                continue
            
            # Filter to companies that priced (not withdrawn)
            if not price:
                continue
            
            candidates.append({
                "symbol": symbol,
                "name": ipo.get("name"),
                "market_cap": None,  # Not provided in IPO calendar
                "sector": None,
                "industry": None,
                "price": None,
                "discovery_source": "finnhub_ipo_calendar",
                "discovery_metadata": {
                    "ipo_date": ipo.get("date"),
                    "exchange": exchange,
                },
            })
    except Exception as e:
        logger.warning(f"IPO discovery failed: {e}")
    
    return candidates


# === FILTERING ===

def should_exclude(candidate: dict) -> bool:
    """Apply exclusion filters to a candidate."""
    symbol = candidate.get("symbol", "")
    name = (candidate.get("name") or "").lower()
    
    # Symbol suffix check (warrants, units, rights)
    for suffix in EXCLUSION_FILTERS["symbol_suffixes"]:
        if symbol.endswith(suffix):
            return True
    
    # Name pattern check
    for pattern in EXCLUSION_FILTERS["name_contains"]:
        if pattern in name:
            return True
    
    # Length sanity check
    if len(symbol) > 5:
        return True  # Probably not a regular common stock
    
    return False


# === TIER ASSIGNMENT ===

def assign_tier(candidate: dict) -> str:
    """Assign a tier based on candidate characteristics."""
    market_cap = candidate.get("market_cap") or 0
    source = candidate.get("discovery_source", "")
    
    # IPOs go to their own tier
    if "ipo" in source:
        return "tier_4_ipo_discovery"
    
    # Small caps go to tier 3
    if market_cap < 500_000_000:
        return "tier_3_small_cap"
    
    # Breakout zone is the bulk
    if market_cap < 10_000_000_000:
        return "tier_2_breakout_zone"
    
    # Larger companies go to tier 1
    return "tier_1_large_mid"


# === DB OPERATIONS ===

def get_existing_symbols() -> set:
    """Get the set of symbols already in the universe."""
    conn = get_db_connection()
    rows = conn.execute("SELECT symbol FROM universe_symbols").fetchall()
    return {row[0] for row in rows}


def insert_into_universe(candidates: list[dict]) -> int:
    """Insert new candidates into universe_symbols. Returns count inserted."""
    conn = get_db_connection()
    now = datetime.utcnow().isoformat()
    
    inserted = 0
    for c in candidates:
        try:
            metadata_json = json.dumps(c.get("discovery_metadata") or {})
            conn.execute("""
                INSERT OR IGNORE INTO universe_symbols 
                (symbol, name, sector, industry, market_cap, tier, 
                 refresh_days, discovery_source, discovery_metadata, 
                 added_at, last_screened_at)
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """, (
                c.get("symbol"),
                c.get("name"),
                c.get("sector"),
                c.get("industry"),
                c.get("market_cap"),
                c.get("tier"),
                c.get("refresh_days"),
                c.get("discovery_source"),
                metadata_json,
                now,
                now,
            ))
            inserted += conn.total_changes  # crude — adjust based on actual cursor
        except Exception as e:
            logger.warning(f"Failed to insert {c.get('symbol')}: {e}")
    
    conn.commit()
    return inserted
```

@router.get("/api/admin/universe/stats")
async def get_universe_stats():
    """Get universe statistics broken down by tier and source."""
    conn = get_db_connection()
    
    total = conn.execute("SELECT COUNT(*) FROM universe_symbols").fetchone()[0]
    
    by_tier = {}
    rows = conn.execute("""
        SELECT tier, COUNT(*) FROM universe_symbols GROUP BY tier
    """).fetchall()
    for tier, count in rows:
        by_tier[tier or "unassigned"] = count
    
    by_source = {}
    rows = conn.execute("""
        SELECT discovery_source, COUNT(*) FROM universe_symbols 
        GROUP BY discovery_source
    """).fetchall()
    for source, count in rows:
        by_source[source or "legacy"] = count
    
    by_sector = {}
    rows = conn.execute("""
        SELECT sector, COUNT(*) FROM universe_symbols 
        GROUP BY sector
        ORDER BY COUNT(*) DESC
    """).fetchall()
    for sector, count in rows:
        by_sector[sector or "unknown"] = count
    
    return {
        "total": total,
        "by_tier": by_tier,
        "by_source": by_source,
        "by_sector": by_sector,
    }

## Step 9: Watch for issues

Things to watch for in the first few days:

1. **Crawler keeping up** — The new symbols will surge into the
   queue as "never evaluated." The crawler should chew through
   them on its existing schedule. If processing is too slow we'll
   tweak crawler behavior in a follow-up prompt.

2. **API rate limits** — More symbols = more API calls. Watch for
   429 errors from any provider.

3. **Data quality on new symbols** — Small caps often have worse
   data coverage. The breakout score's hard filters will reject
   most, but watch for spurious high scores from incomplete data.
